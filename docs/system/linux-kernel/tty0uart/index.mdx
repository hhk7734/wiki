- /sys/class/tty/xxx/device 링크가 존재해야 함
- linux/serial_core.h (uart_driver \<-\> tty_driver)
- normal serial ports == N_TTY
- platform_device와 platform_driver의 name이 같아야 연결 됨

## Flow control

- DCD: Data Carrier Detect
- RXD: Receive Data
- TXD: Transmit Data
- DTR: Data Terminal Ready
- DSR: Data Set Ready
- RTS: Request To Send
- CTS: Clear To Send
- CD: Carrier Detect
- RI: Ring Indicator

TXD -> RXD

RTS -> CTS

DTR -> DSR
