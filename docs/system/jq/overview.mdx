## 실시간 json log 파싱

For human-readable streaming logs, use `jq` to colorize JSON lines and pass
non-JSON lines through unchanged. The `sed` stage expands escaped `\n` and
`\t` sequences for readability.

```shell
alias log2jq="jq -rRC --unbuffered '. as \$line | try fromjson catch \$line' | sed -u 's/\\\\n/\\n/g; s/\\\\t/\\t/g'"
```

```shell
<program> | log2jq
```
