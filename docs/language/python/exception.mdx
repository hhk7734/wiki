## try-except

```python
try:
    ...
except Exception as e:
    ...
else:
    ...
finally:
    ...
```

| 정상 |         | 비정상 |
| :--: | :-----: | :----: |
|  ✓   |   try   |   ✓    |
|      | except  |   ✓    |
|  ✓   |  else   |        |
|  ✓   | finally |   ✓    |

## Exception hierarchy

- [Built-in Exceptions](https://docs.python.org/3.12/library/exceptions.html)

```shell
BaseException # 사용하지 말 것

├── KeyboardInterrupt
├── GeneratorExit
└── Exception # 일반적으로 사용자 정의 예외는 이 클래스를 상속받아 생성

    ├── StopAsyncIteration
    ├── ArithmeticError

    ├── BufferError
    ├── EOFError
    ├── ExceptionGroup [BaseExceptionGroup]
    ├── ImportError
    │   └── ModuleNotFoundError
    ├── LookupError
    │   ├── IndexError
    │   └── KeyError
    ├── MemoryError
    ├── NameError
    │   └── UnboundLocalError
    ├── OSError
    │   ├── BlockingIOError
    │   ├── ChildProcessError
    │   ├── ConnectionError
    │   │   ├── BrokenPipeError
    │   │   ├── ConnectionAbortedError
    │   │   ├── ConnectionRefusedError
    │   │   └── ConnectionResetError
    │   ├── FileExistsError
    │   ├── FileNotFoundError
    │   ├── InterruptedError
    │   ├── IsADirectoryError
    │   ├── NotADirectoryError
    │   ├── PermissionError
    │   ├── ProcessLookupError
    │   └── TimeoutError
    ├── ReferenceError
    ├── RuntimeError # 다른 범주에 속하지 않는 에러가 감지될 때
    │   ├── NotImplementedError
    │   └── RecursionError
    ├── SyntaxError
    │   └── IndentationError
    │        └── TabError
    ├── SystemError

    ├── ValueError # 연산이나 함수가 올바른 형이지만 부적절한 인자를 받았을 때
```
