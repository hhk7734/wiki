## User

### User 생성

- https://www.postgresql.org/docs/current/sql-createuser.html

```sql
CREATE USER <user> WITH PASSWORD '<password>'
```

`CREATE USER`는 `CREATE ROLE ... LOGIN`과 동일한 것으로 간주하면 됩니다.

### User 암호 변경

```sql
ALTER USER <user> WITH PASSWORD '<password>'
```
