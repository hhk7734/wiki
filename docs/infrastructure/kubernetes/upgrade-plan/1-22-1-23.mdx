- 클러스터 버전 확인

```shell
kubectl version --short
```

- 노드 버전이 현재 클러스터 버전과 일치하는지 확인

```shell
kubectl get nodes
```

- 기본 보안 정책 존재 확인

```shell
kubectl get psp eks.privileged
```
