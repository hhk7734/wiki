## Layout of folders and files

```shell
Arduino
└── libraries
    └── my_lib/
        ├── examples/
        ├── keywords.txt
        ├── library.properties
        └── src/
            ├── my_lib.cpp
            └── my_lib.h
```

## Library metadata

### library.properties

```ini title="library.properties"
name=
version=
author=
maintainer=
sentence=
paragraph=
category=[Display|Communication|Signal Input/Output|Sensors|Device Control|Timing|Data Storage|Data Processing|Other]

architectures=*
# optional

includes=
precompiled=
ldflags=
```
